# Football rich club crests — 2026/27

This directory records the club-logo mapping used by Football rich.

- Coverage: the five leagues Premier League, La Liga, Bundesliga, Serie A and Ligue 1.
- The source collection contains 111 team entries, including additional clubs that may appear in historical match records.
- The app loads direct static PNG image files from the ESPN logo CDN. It does **not** call ESPN sports-data APIs and does not retrieve fixtures, scores, standings or statistics from ESPN.
- Team names are normalized and common aliases are mapped to the same crest. If an image cannot load, the existing initials fallback remains active.
- Existing J.League crest links are preserved.

Source collection: https://github.com/frertommy/team-logos  
Source manifest: https://raw.githubusercontent.com/frertommy/team-logos/main/manifest.json
