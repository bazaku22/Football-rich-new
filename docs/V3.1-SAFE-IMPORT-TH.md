# Football rich V3.1 — Safe Existing Match Analysis Update

V3.1 adds a safe import mode for replacing the active analysis of an existing fixture without replacing its identity or history.

## Default mode
The import screen enables **Update existing match only** by default. In this mode every report must resolve to exactly one existing match using:
- Competition identity (with a tolerant UEFA Nations League label match)
- Normalized home-team identity
- Normalized away-team identity
- Kickoff timestamp within two minutes

If no match is found or more than one match is found, the entire batch is rejected before any write. The importer never creates a new match in this mode.

## Write behavior
For each resolved match:
- Reuse the existing `matches.id` as `matchId`.
- Append a new `analyses` record with the next version number.
- Append research and source-evidence records linked to that same Match ID.
- Do not update the match row, existing analyses, predictions, match results, or performance history.
- Reject previously imported report IDs.
- Save the complete original report payload for provenance.

All reports in the batch are written in one IndexedDB transaction. A transaction failure aborts the complete batch.

## Backward compatibility
The checkbox can be unchecked to retain the prior general import behavior, including creating a new match when no existing match is found. The safe existing-only mode is checked by default.
