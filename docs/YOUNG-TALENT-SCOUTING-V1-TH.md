# Young Talent Scouting V1 — ขอบเขตและกติกา

## หน้าจอ
- เพิ่มเมนู `ดาวรุ่ง` เป็นพื้นที่แยกจาก Match Center เดิม
- ใช้รายการจัดอันดับเพียงชุดเดียว ไม่มีการแยกหมวดเกรดหรือมูลค่า
- การ์ดหน้าแรกแสดงอันดับ รูปนักเตะ โลโก้สโมสร ชื่อและเบอร์เสื้อ และเสื้อจิ๋วมุมมองด้านหลัง
- หน้าโปรไฟล์แสดงรูปนักเตะเป็นภาพหลัก และวางเสื้อจิ๋วต่อท้ายชื่อ
- รองรับแท็บภาพรวม สถิติ ประวัติการแข่งขัน และพัฒนาการ

## กติกาการจัดอันดับ
1. เกรดเป็นตัวจัดอันดับหลัก (A+ ถึง F)
2. เมื่อเกรดเท่ากัน มูลค่า ETV ที่สูงกว่าอยู่ก่อน
3. ผู้เล่นที่ยังไม่มีเกรดอยู่ท้ายรายการ
4. หากเกรดและมูลค่าเท่ากัน ให้คงลำดับเดิมใน Watchlist
5. ใช้รายการเดียวตลอด ไม่มีตัวเลือกแยกการจัดอันดับตามเกรดหรือมูลค่า

## ข้อมูลและการจัดเก็บ
- เกรดและมูลค่าแก้ไขได้จากหน้าโปรไฟล์
- มูลค่ากรอกเป็นล้านยูโร (ETV) โดยอ้างอิง FootballTransfers เมื่อมีข้อมูลที่ตรวจสอบได้
- คะแนนเรตติ้งแมตช์ใช้ FotMob เป็นแหล่งหลักเพียงแหล่งเดียว; หากไม่มีข้อมูลให้แสดง N/A
- รายชื่อเริ่มต้น 4 คน: Nico Paz, Mikey Moore, Jonas Urbig, Shea Lacey
- เกรดและมูลค่าของผู้เล่นเริ่มต้นเป็นค่าว่าง ไม่ได้สมมติขึ้น
- บันทึก Watchlist ใน `app_settings` ด้วย key `young_talent_watchlist_v1` ไม่เพิ่ม Object Store ใหม่และไม่เปลี่ยนโครงสร้างฐานข้อมูล
- ข้อมูลคู่แข่งขัน บทวิเคราะห์ คำทำนาย และผลการแข่งขันเดิมไม่ถูกแก้ไขหรือลบ

## ภาพและหมายเลขเสื้อ
- ภาพผู้เล่นและโลโก้สโมสรโหลดจาก URL ภายนอก จึงต้องมีอินเทอร์เน็ตเพื่อแสดงภาพ
- หากภาพโหลดไม่ได้ จะแสดงอักษรย่อแทนภาพผู้เล่น/ตราสโมสร
- หมายเลขตัวอย่างที่ใส่ใน Watchlist: Nico Paz 10, Mikey Moore 47, Jonas Urbig 40, Shea Lacey 31
- Mikey Moore แสดงสโมสรปัจจุบัน 1. FC Köln พร้อมหมายเหตุว่ายืมตัวจาก Tottenham Hotspur
- เสื้อเป็นภาพเวกเตอร์จำลองตามสีทีม/ผู้รักษาประตู ไม่ใช่ภาพจำลองชุดแข่งลิขสิทธิ์แบบตรงทุกลาย

## การทดสอบ
- มี unit tests ตรวจสอบ: เกรดเหนือกว่ามูลค่าที่สูงกว่า, มูลค่าสูงกว่าเมื่อเกรดเท่ากัน, ลำดับเดิมเมื่อคะแนนเท่ากัน, และผู้เล่นที่ยังไม่ประเมินอยู่ท้ายรายการ
